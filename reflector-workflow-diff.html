What was removed

  • _PIXEL_DIFF_THRESHOLD = 0.02 — the 2% magic-number constant
  • _pixel_diff_ratio() — OpenCV absolute-diff comparison method
  • Section 3b early-return block — 71 lines that auto-passed steps when pixel change was below threshold
  • Silent short_circuit: true in reflector_report.json — no more hidden skips in the research log
  • Special action_type != "input" carve-out — the exception set is now irrelevant

What was kept / gained

  • start_app ADB foreground check — unchanged, still bypasses LLM correctly
  • _encode_image() — still uses cv2 for WebP compression, no changes
  • Figma Gold Standard 3-way verification on final step — unchanged
  • MIRIX episodic memory updates — now every step writes a real LLM verdict
  • Every intermediate step now produces a genuine LLM-verified verdict
  • All reflector_report.json files now contain real reasoning, never a fabricated skip
  • Thesis data is clean — total_reflector_calls now equals actual LLM calls made
Code paths: Before = 3 exit paths (start_app · pixel-diff skip · LLM)  →  After = 2 exit paths (start_app · LLM)
